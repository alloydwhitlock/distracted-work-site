Install

Distracted Work is a browser extension that blocks distracting websites and reminds you to get back to work.

Available on Firefox

Install Extension →

Free · Open source · No data collected

How It Works

  1. Install the extension from Firefox Add-ons.
  2. Add sites you find distracting to your blocklist.
  3. When you visit a blocked site, you'll see a random motivational message reminding you to focus.
  4. Optionally set a schedule so sites are only blocked during work hours.

Features

  • Block any website by domain
  • Temporary or permanent blocking
  • Schedule-based blocking (e.g., 9 AM to 5 PM on weekdays)
  • 17 visual themes (Nord, Catppuccin, Tokyo Night, Dracula, and more)
  • Light, dark, and auto theme modes
  • Zero data collection — everything stays on your device
